# Player Profile - Talent ID prototype

A prototype of an individual player profile for talent identification, built for a technical exercise.

**Every player, scout, rating, injury and measurement on this site is synthetic.** The data was generated;
no real person is represented. The page says so in its banner.

The site is the built output only. The pipeline that produces it (ingestion, matching, validation, the model
and its checks) is not published here.

Built 2026-10-12.
